## 🚀 संचालन निर्देश (Run & Build Instructions)

### 1. डेवलपमेंट सर्वर चलाएं:
```bash
npm run dev
```
ब्राउज़र में खोलें: `http://localhost:3000`

### 2. स्टेटिक प्रोडक्शन बिल्ड तैयार करें:
```bash
npm run build
```
बिल्ड पूरा होने पर `out/` डायरेक्टरी में पूर्णतः स्टेटिक वेबसाइट तैयार हो जाएगी।

### 3. Vercel पर होस्टिंग निर्देश (Vercel Deployment Guide):

यह प्रोजेक्ट Next.js 15 स्टेटिक एक्सपोर्ट पर आधारित है तथा Vercel के लिए `vercel.json` एवं `.gitignore` के साथ पूरी तरह तैयार है:

#### विधि A: GitHub के माध्यम से (अनुशंसित - ऑटोमैटिक डिप्लॉयमेंट):
1. अपने प्रोजेक्ट को GitHub रिपॉजिटरी में पुश करें:
   ```bash
   git init
   git add .
   git commit -m "कमला देवी ट्रस्ट वेबसाइट प्रथम संस्करण"
   git branch -M main
   git remote add origin https://github.com/<आपका-यूजरनेम>/<रिपॉजिटरी-नाम>.git
   git push -u origin main
   ```
2. [vercel.com](https://vercel.com) पर जाएं और लॉगिन करें।
3. **"Add New Project"** पर क्लिक करें और अपनी GitHub रिपॉजिटरी को आयात (Import) करें।
4. Vercel स्वतः Next.js को पहचान लेगा। **"Deploy"** बटन दबाएं।
5. 1 मिनट के भीतर आपकी वेबसाइट लाइव हो जाएगी और आपको मुफ्त `.vercel.app` डोमेन मिल जाएगा जिसे आप अपने कस्टम डोमेन (उदा. `kamladevitrust.org`) से जोड़ सकते हैं।

#### विधि B: Vercel CLI के माध्यम से (टर्मिनल से सीधा डिप्लॉय):
1. टर्मिनल में Vercel CLI चलाएं:
   ```bash
   npx vercel
   ```
2. स्क्रीन पर पूछे जाने वाले प्रश्नों का उत्तर दें (Enter दबाते जाएं)।
3. प्रोडक्शन डिप्लॉय हेतु:
   ```bash
   npx vercel --prod
   ```

#### अन्य प्लेटफॉर्म्स:
- **Netlify / Cloudflare Pages / GitHub Pages**: `out/` डायरेक्टरी को सीधे ड्रैग-एंड-ड्रॉप या कनेक्ट कर सकते हैं।
- **cPanel (Shared Hosting)**: `out/` के अंदर की समस्त फाइलों को सीधे `public_html` में अपलोड करें।
